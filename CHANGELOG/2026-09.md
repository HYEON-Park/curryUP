## 2026-09-02

### 문서작성 대상을 "오늘의 추천공고"로 단일화 (평점 null 공고 누락 결함 수정)
- **증상**: UPDATE 체인의 문서작성 배치(09-02 18:19~18:25 KST, success)가 오늘의 추천공고 3건 중 평점이 `null`인 2건(㈜커머스톤 70%·㈜홀빅 74%)의 문서를 하나도 만들지 않음. 평점 4.3인 ㈜파란샘만 생성됨.
- **원인**: 추천공고 판정과 문서작성 대상 판정이 평점 `null` 처리에서 갈림(규칙 이원화).
  - 추천공고(`utils/recommendations.getRecommendations`): `rating === null || rating >= 2.8` → 평점 미확인 **포함**.
  - 문서작성 대상(`writeDocumentsJob.countTargets` + 프롬프트 + SKILL "평점 없음은 제외"): `parseFloat(null)=NaN >= 2.8`=false → 평점 미확인 **제외**.
  - 커머스톤·홀빅은 매칭률(70·74%)은 있으나 평점조회에서 잡플래닛 평점을 못 찾아 `rating: null` → 추천엔 뜨지만 문서작성 대상에서 빠짐.
- **조치**: 문서작성 대상 = **오늘의 추천공고 ∪ 즐겨찾기**로 단일화. `countTargets`(평점 문턱 재계산)를 제거하고 `collectDocTargets`가 `getRecommendations`를 그대로 재사용 + 즐겨찾기(미종료)를 합쳐 coverLetter 있는 공고만 제외. 매칭률 배치와 동일하게 **서버가 대상 id 목록을 확정해 프롬프트에 주입**하고, Claude는 평점·매칭률·연차로 다시 거르지 말고 지정 id만 전부 작성하도록 지시(판정 이원화 원천 차단).
- 수정(백엔드): `backend/src/scheduler/writeDocumentsJob.ts`.
- 수정(스킬): `.claude/skills/write-documents/SKILL.md` — 문서생성 기준을 추천공고 기준(평점 null 포함, 2.8 미만만 제외)으로 정정 + 배치 주입 id 목록 우선 원칙 명시. 연차 필터 제외 규칙은 대상 선정에서 제거(추천공고 기준과 일치).
