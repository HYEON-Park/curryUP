# curryUP

사용자 프로필(경력, 기술 스택, 희망 직무 등)을 기반으로 채용 공고를 매일 자동 수집·매칭하고, 공고별로 AI가 맞춤형 자기소개서/소개/경력사항을 생성해 웹 대시보드로 보여주는 개인용 구직 도구입니다.

## 주요 기능

- **자동 수집·매칭** — 매일 00:00 사람인·잡코리아에서 공고를 수집하고, 프로필 기반 매칭 엔진으로 필터링합니다.
- **AI 문서 자동 생성** — 매일 23:00 배치로 공고별 자기소개서·소개·경력사항을 로컬 LLM(Ollama)이 생성합니다.
- **대시보드** — 매칭된 공고를 카드 형태로 확인하고, 카드 클릭 시 생성된 문서를 탭으로 조회합니다.
- **공고 관리** — 카드 우측 하단 [×] 버튼으로 불필요한 공고를 숨김 처리하고, 관리자 페이지에서 복구·영구 삭제할 수 있습니다.
- **관리자 페이지** — 배치 수동 실행·이력 조회([배치 모니터링 및 제어])와 숨김 공고 관리([대쉬보드 관리])를 탭으로 제공합니다.

## 아키텍처

- **frontend/** — React + Vite. 프로필 입력, 공고 대시보드, 공고 상세(자기소개서/소개/경력사항 탭) 페이지.
- **backend/** — Express + TypeScript. 사람인·잡코리아 스크래퍼, 매칭 엔진, AI 문서 생성 파이프라인, node-cron 스케줄러.
  - 개발 모드에서는 Vite를 미들웨어로 품어서 포트 4000 하나로 API와 프론트엔드(HMR 포함)를 함께 서빙합니다.
  - 프로덕션 모드(`NODE_ENV=production`)에서는 `frontend/dist` 정적 빌드를 서빙합니다.
- **AI 엔진** — 로컬 [Ollama](https://ollama.com) (`qwen2.5:14b` 기본값). API 키 없이 동작합니다.
- **SKILL.md** (프로젝트 루트) — 크롤링 대상 채용 사이트 URL 목록. 직접 편집해서 관리합니다.

## 시작하기

### 1. Ollama 설치 및 모델 준비

```sh
# https://ollama.com 에서 설치 후
ollama pull qwen2.5:14b
```

### 2. 의존성 설치

```sh
cd backend && npm install
cd ../frontend && npm install
```

### 3. 개발 서버 실행

```sh
cd backend
npm run dev   # http://localhost:4000 — API + 프론트엔드(HMR) 동시 서빙
```

### 4. 프로덕션 빌드 및 실행

```sh
cd backend
npm run build   # backend tsc + frontend vite build
npm start       # http://localhost:4000
```

## 사용 방법

1. `http://localhost:4000/profile` 에서 프로필을 입력하고 저장합니다.
2. 루트의 `SKILL.md`에 크롤링할 채용 공고 검색 URL을 추가합니다.
3. 매일 00:00 자동으로 공고를 수집·매칭합니다. D-0/D-1(오늘·내일 마감) 공고는 수집 및 표시에서 자동 제외됩니다.
4. 매일 23:00 AI 배치가 당일 쌓인 미생성 공고의 문서를 일괄 처리합니다(건당 약 4~5분, CPU 추론).
5. 백엔드가 스케줄 시각에 꺼져 있었다면 **다음 기동 시점에 즉시 따라잡아(catch-up) 실행**합니다.
6. 대시보드에서 공고 카드를 클릭하면 상세 페이지에서 생성된 문서를 확인할 수 있습니다.
7. 카드 우측 하단 [×] 버튼으로 공고를 숨기고, `http://localhost:4000/admin` [대쉬보드 관리] 탭에서 복구하거나 영구 삭제할 수 있습니다.

## 관리자 페이지 (`/admin`)

| 탭 | 기능 |
|----|------|
| 대쉬보드 관리 | 숨김 처리된 공고 목록 조회, 개별·일괄 복구, 선택/전체 영구 삭제 |
| 배치 모니터링 및 제어 | 스크래핑·알림·AI 배치 수동 실행, 실행 이력 조회 |

## 자동 시작 (선택)

백엔드가 항상 켜져 있어야 스케줄(수집/배치/알림)이 정시에 동작합니다. Windows 로그온 시 자동 실행을 등록하려면:

```sh
cd backend
npm run build
powershell -ExecutionPolicy Bypass -File .\scripts\register-startup-task.ps1
```

제거하려면 `schtasks /delete /tn CurryUpBackend /f`. 코드를 변경했다면 `npm run build`를 다시 실행해야 반영됩니다.
